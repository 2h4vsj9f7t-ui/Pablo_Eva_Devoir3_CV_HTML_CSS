# CV HTML / CSS
Projet de création d'un cv en HTML5 et CSS3.
## Technologies utilisées 
- HTML 5
- CSS3
- Flexbox
- Google Fonts : Lato et Raleway
  ## Fonctionnalités
  - Mise en page en deux colonnes
  - Photo de profil
  - Liens de contact
  - Effets au survol
  - Organisation des fichiers en sous-dossiers
